# 像素素材与接入约束

本目录为用户确认的「美术提案 01 / 海面巡航」中的 11 个原创程序化 SVG，2026-11-05 通过 Library 官方传输取回。来源美术包：`libfile_02398f1ac0048191880bdec8ab31a560`，版本 0；概念板：`libfile_44d490243cf081919691d461038f6d4e`，版本 0。SVG 字节与审阅包一致；未使用第三方角色、外部字体或运行时网络素材。

概念板为 ImageGen 生成的方向参考，没有裁切入游戏。接入使用包内低分辨率像素样稿，不能宣称达到概念板全部细节；后续精修可保持同一视觉方向。大型敌机是玩法候选，没有复制或启用。保留项目名称「打飞机 / Airplane Fight」，没有采用「SKY PATROL」候选名称。

SVG 使用 `crispEdges`，CSS 使用 `image-rendering: pixelated`。飞机与道具原始网格为 32×32，海面为 180×320。菜单主机使用整数倍网格；战斗视觉按原有碰撞 DOM 尺寸显示，不能为整数倍像素擅自扩大碰撞范围。

碰撞元素保留主机 46×48、敌机 40×42、子弹 4×14、道具 40×44 CSS px，原有道具脉冲仍在。护盾环和爆炸是装饰，不参与碰撞。减弱动态效果设置关闭装饰动画，定时清理仍执行。所有速度、掉落、得分与射击规则沿用第一阶段。

色板：主底 `#081826`、海面 `#123643`、主操作/护盾 `#71F6CB`、正文/主机 `#F3F1DD`、敌机 `#FF776B`、分数/火力 `#FFD486`。中文与数字使用系统字体，正文不使用难读的像素字体。按钮至少 44px 高，小屏菜单主操作至少 46px。
