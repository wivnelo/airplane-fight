# 私人试玩准备

[项目入口](../README.md) · [本轮验证和阻塞](../STATUS.md) · [回归命令](TESTING.md)

当前仓库是可本地运行的完整前后端，没有构建步骤。本页给出私人试玩方案，不代表已经部署或已经产生手机访问链接。`127.0.0.1` 只指向打开浏览器的那台设备；云环境内的本地地址不能直接在手机打开。

## 先在运行代码的电脑预览

要求 Node 24+，在原分支仓库根目录执行：

```bash
npm --prefix backend ci
node scripts/playtest.cjs
```

终端显示实际本机 URL，默认端口 3100；端口被占用时可以用 `node scripts/playtest.cjs 0` 自动选择空闲端口。此启动器始终只监听 `127.0.0.1`，不读取 HOST/DATA_DIR 来扩大访问或接入已有数据，不建隧道。不能用它直接分享给手机。

每次创建独立临时空榜单，不导入或更改 `backend/data/leaderboard.json`。Ctrl+C 正常停止后关闭端口并删除本次临时榜单；崩溃或强杀可能留下临时目录，不自动删除不明目录。浏览器本机最佳仍保留；重新启动空数据库后，旧待提交凭证可能被拒绝，因此试玩前先等同步结束，或使用独立浏览器配置，避免混用已有成绩。

## 手机接入选项（选择并确认后才执行）

| 方案 | 需要什么、准备执行什么 | 服务和费用 | 访问与数据边界 |
| --- | --- | --- | --- |
| 自有电脑与手机在可信同一 Wi-Fi（最少新服务） | 在该电脑检出原分支并安装 Node 24+；用独立临时 DATA_DIR 启动既有后端，仅绑定明确的局域网 IP；防火墙仅允许手机 IP 访问选定端口；现场检查手机可达 | 不需购买域名、云主机或订阅；电脑须开机，有本机资源/电力开销 | 当前应用无登录，不能认为“知道链接才可访问”；同网段放行范围内都可连接。HTTP 未加密，不用于公共 Wi-Fi、生产数据或重要凭证；不配置路由器公网端口转发。结束立即停服务并撤销临时防火墙规则 |
| 已有私人 Tailscale 网络 + Serve（可跨 Wi-Fi） | 用户指定受控主机、手机和账号；检查访问规则只允许指定用户/设备；应用仍监听本机，Serve 提供私人 HTTPS；仅将实际 HTTPS 来源加入 ALLOWED_ORIGINS；实际验收后再给手机链接 | 需电脑/受控主机与手机客户端。官网当前列 Personal 为 $0，但是否适用取决于用途、账号套餐和资源用量；云主机另计，不默认购买或升级 | Serve 限于 tailnet，仍须收紧访问规则；不启用 Funnel。若采用云环境，还需支持的 VPN/网络配置与相关账号授权。当前游戏未使用 Tailscale 身份头，不能把代理后的浏览器指纹当可靠个人身份 |
| 独立托管的带访问控制测试站 | 用户先指定托管账号、授权访问对象、预算上限与保留时长；再准备访问网关、HTTPS、独立持久卷/测试数据、回退与关闭办法 | 托管、存储、网关或域名可能计费，选择服务和核价前不执行 | 属于对外部署，必须另获明确授权；应用本身无登录，不能只靠随机网址或 robots.txt 保密。暂未选择提供商或创建资源 |

参考：[Tailscale Serve 官方文档](https://tailscale.com/docs/features/tailscale-serve)说明 tailnet 范围、HTTPS 和访问规则；[当前价格](https://tailscale.com/pricing)需在实际开通前复核。这里建议优先复用自有电脑或已有私人网络，而不预设购买新服务。

经代码核对，HTTPS 代理方案需要把最终访问来源精确配置为 `ALLOWED_ORIGINS`；目前后端不信任转发协议/IP，不应为了试玩直接开启宽泛 `trust proxy` 或允许所有来源。使用代理时多个设备的来源 IP 可能一致，现有限流和浏览器推导身份会共享或合并，适合个人体验，不代表竞技排名验证。

## 需要用户确认的具体信息

- 手机型号与系统；能否使用同一 Wi-Fi 下的自有电脑，还是必须跨网络访问。
- 若用私人网络：现有账号、指定主机、允许访问的用户/设备，以及是否允许安装客户端、启用 HTTPS/Serve 和修改访问规则。
- 若用托管：提供商/账号、费用上限、访问身份与期限、测试成绩是否留存。确认前不创建资源或启动外部监听。

## Safari / WebKit 验证入口

Chromium 中模拟手机尺寸和触摸，不等于 Safari。Playwright 的 WebKit 也并非 Apple Safari，其官方说明指出它依赖定制补丁、功能仍受运行平台影响：[Playwright 浏览器说明](https://playwright.dev/docs/browsers#webkit)。

当前 UI 脚本支持选择 WebKit 引擎，安装完成后可执行：

```bash
# 以下安装和测试需环境允许官方浏览器下载，并具备所需系统依赖。
PLAYWRIGHT_BROWSERS_PATH=/tmp/airplane-browsers python3 -m playwright install webkit
PLAYWRIGHT_BROWSERS_PATH=/tmp/airplane-browsers BROWSER_ENGINE=webkit python3 tests/browser_ui.py
```

如果网络策略阻止下载，使用环境设置增加安装器实际报告的官方域名并重新应用配置，不换镜像绕过。之后仍可能需要安装 WebKit 系统依赖；没有运行成功前不得标记通过。Safari 真机需在 iPhone/iPad 上另验。

## 手机到手后的验收

1. 首次打开，主菜单和开始按钮完整可见；读完手机操作提示能开始。
2. 单指按住射击，左右拖动、纵向偏移、松手；确认不滚页、不残留射击，边缘能躲避。
3. 击破计分、无盾碰撞结束、立即重开；四类道具和计分沿用既有规则。
4. 暂停、排行榜往返、切后台、锁屏再回来，必须主动继续；确认道具计时冻结。
5. 竖横切换与浏览器工具栏伸缩，确认飞机仍在边界内、按钮可点；不强制旋转。
6. 在真机扬声器/耳机听命中音：开关静音、恢复前台、继续后声音；设备静音键、蓝牙和系统音量分别记录。
7. 飞行中断网、结束后恢复网、重开、刷新；确认未同步状态和重试，不能把无凭证离线局当已上榜。
8. 记录设备/系统/浏览器、步骤、预期/实际和复现频率。试玩分数只进独立测试库，不导入生产榜单。

自动脚本中的音频信号检查，只证明 Web Audio 产生或停止波形；它不证明真机音量、延迟、音质或扬声器可听。
