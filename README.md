## 打飞机小游戏

基于 HTML、CSS、原生 JavaScript 的小型“打飞机”游戏，界面采用手机竖屏比例，可用鼠标或触摸左右移动飞机并发射子弹击落敌机。

### 功能特性

- 敌机下落速度与生成频率会随时间逐步提升，难度持续升级。
- 支持鼠标（含空格键）与触摸双模式操作，长按即可持续射击。
- 集成排行榜：基于设备指纹自动生成唯一昵称并提交成绩（需开启下方 Node.js 服务）。
- 命中敌机时会播放合成音效并触发爆炸动画，反馈更加明显。
- 右上角“排行榜”按钮可调出排行榜面板，左上角“返回游戏”按钮可以随时返回战斗。
- 左上角“音效”开关能快速静音/恢复命中音效，游戏体验更可控。
- 每 30 秒随机掉落彩色飞机道具，可提供限时火力提升（×2/×3/×4，持续 20/15/10 秒）。
- 护盾道具可获得 5 秒防护，被撞击时会直接摧毁敌机并加分。
- 排行榜按设备自动分配昵称，同一玩家只保留历史最高分。

### 快速开始（前端）

1. 打开 `frontend/index.html` 即可直接游玩，无需额外构建或依赖。
2. 点击界面底部居中的**开始游戏**按钮。
3. 鼠标在游戏区域内左右移动控制飞机位置，按住鼠标左键或空格键持续射击。
4. 击落敌机加分，被撞到则游戏结束，成绩自动提交至排行榜（服务端运行时）。
5. 需要查看排行榜时，点击右上角“排行榜”，随后可在左上角点击“返回游戏”继续游玩。
6. 每 30 秒会有随机道具从上方坠落：彩色飞机提升火力，蓝绿色飞机提供护盾。

### 启动排行榜服务（Node.js）

1. 进入目录：`cd backend`
2. 安装依赖：`npm install`
3. 启动服务：`npm run dev`（默认监听 `http://localhost:3000`）
4. 再次打开 `frontend/index.html`，成绩会按当前设备指纹自动记录并提交至本地服务器。

服务器提供的 REST 接口：

| 方法 | 路径 | 说明 |
| ---- | ---- | ---- |
| `GET` | `/api/leaderboard` | 返回按分数由高到低排序的排行榜数据（默认最多 50 条）。 |
| `POST` | `/api/leaderboard` | 提交一条新成绩，body：`{ score: number }`。 |
| `GET` | `/health` | 健康检查。 |

> 成绩会根据设备指纹自动归档；同一设备再次提交时，仅保留历史最高分。

### 排行榜数据表设计

排行榜持久化存储于 `backend/data/leaderboard.json`，结构示意如下：

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| `id` | `string` | 成绩唯一标识（UUID）。 |
| `fingerprint` | `string` | 由 IP、User-Agent 等信息哈希得到的设备指纹（前 32 位）。 |
| `displayName` | `string` | 基于指纹生成的可读昵称，例如 `飞行员-1A2B3C4D`。 |
| `score` | `number` | 玩家最高得分，向下取整并限制为非负。 |
| `playedAt` | `string` | ISO 8601 时间戳，记录提交时间。 |

服务器会按 `score` 降序、`playedAt` 升序排列，保留最高 50 条记录，可根据需要接入真实数据库进一步扩展。
